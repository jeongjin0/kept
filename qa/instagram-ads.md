# Visible Instagram advertisement exclusion · 0.3.6

2026-10-09 KST. Native QA of the first 0.3.6 candidate found a disclosed Instagram advertisement with two likes being skipped under the default 5,000-like minimum. Its normal feed card displayed `Ad` and a call to action. A captured two-like reason chip followed the advertisement. Ads must stay, so this candidate was held for correction; its ZIP was not released.

The adapter now also checks the current player's visible `Ad`, `Sponsored` or Korean advertisement disclosure. A small visible label must share a bounded player container with the visible video. Wide desktop captions beside the video and compact captions over it are covered. The guard leaves the active advertisement alone and rechecks before automatic forward navigation. It does not scan the whole page for an advertising keyword, restyle the host, click advertisements or request another API.

## Regression and package checks

Two built-script regressions reproduce wide and compact disclosures with two-like counts and no JSON ad flag. Both fail against the performance-only candidate and pass after the guard. Each verifies that the advertisement stays at the shipped minimum, the counter remains zero, a manually opened ten-like ordinary reel still skips with its reason chip, and Undo restores that ordinary reel. Hidden and offscreen disclosures do not suppress the ordinary reel. The synthetic payload does not establish which fields were present in the native site's response; no native payload was exported.

The full corrected suite passes 28 browser tests with no skipped or flaky results; unit tests pass 45. Type-check, production build and package validation pass. The bridge probe was repeated against the corrected built scripts and retained zero additional cache/player messages and embedded parses during its 2.5-second idle sample. These are controlled-page results, not a CPU or memory benchmark.

The first guard's ZIP (127,075 bytes, SHA-256 b5167ca6efb932432d474712ce159120cfedc96bf112df1f5556e43910550daa) was transferred to the authorized Pro QA host for a native check. The extension files matched the ZIP and the task-owned extension was reloaded normally. A normal Reels feed produced reason chips for 51 and 0 likes. With the extension off, going back identified the card before that zero-reason chip as a clearly labelled image-style advertisement (download call to action, no video and no displayed like count); the 51-like item's identity was not individually verified. The first guard only recognised an advertisement beside a visible video, so this ZIP was also held and is not a release candidate.

The final correction treats any Instagram feed card without a visible video as a non-video card, which is never filtered, and labels a card with a visible disclosure as an advertisement. A same-id observation whose kind changes (for example a player that mounts after its URL and counts) is reconsidered without clearing a user's session Undo, so the ordinary reel after an advertisement still skips and Undo still restores it. The page script also declines automatic forward navigation while an advertisement or non-video card is active.

## Final candidate

The full suite passes 28 browser tests (wide, compact and letterbox advertisement layouts among them) with no skipped or flaky results, and 45 unit tests, including one for the same-id kind change. Type-check, production build and package validation pass. The corrected ZIP is 127,157 bytes, SHA-256 3d6325f8ab76539e791a52e9b6f31f4e577b9c1743d33ddabc510cc4ee71a994. Fourteen of twenty extracted files are identical to published 0.3.5: the manifest, both MAIN bundles and the three isolated site scripts changed, because the shared engine and controller are bundled into each. Background, popup/settings, locales and icons are unchanged. A native sampling of this exact ZIP kept ordinary 5,000+ reels and skipped low-like ones with reason chips, but no disclosed advertisement or image-style card appeared in about 70 frames, so the native advertisement check remains open ([signed-in QA](signed-in-smoke.md#version-036-candidate--2026-10-09)). No earlier package result is carried over to it.
